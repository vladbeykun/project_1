# Анализ A/B-теста рекомендательной системы

Учебный проект по статистическому анализу результатов эксперимента в ленте рекомендаций.

---

## О проекте

**Ситуация:** В ленте рекомендаций тестируется новый алгоритм. Эксперимент проведён с 21 по 27 ноября 2025 года. Группа 1 — контроль (старый алгоритм), группа 2 — тест (новый алгоритм). Задача — оценить, есть ли статистически значимые различия в CTR между группами, и дать рекомендации по результатам теста.

**Тип проекта:** Учебный (курс по анализу данных).

**Данные:** Симулированные данные ClickHouse.

---

## Стек

`Python` `Pandas` `NumPy` `SciPy` `Matplotlib` `Seaborn` `ClickHouse` `pandahouse`

## Методология

### Основная метрика
- **CTR ** — отношение лайков к просмотрам на пользователя

### Применённые статистические тесты

| Тест | Зачем | Результат |
|------|-------|-----------|
| **T-тест (исходный CTR)** | Базовая проверка различий средних | p-value = 0.69 — различий не выявлено |
| **T-тест (сглаженный CTR)** | Учёт проблемы малых выборок (сглаживание через α=5) | p-value = 0.052 — на границе значимости |
| **Тест Манна-Уитни** | Непараметрический тест, устойчивый к выбросам | p-value ≈ 0 — сильные различия |
| **Пуассоновский бутстреп** | Оценка различий глобального CTR без предположений о распределении | Тестовая группа проигрывает контрольной |
| **Манна-Уитни поверх бакетного преобразования** | Более точный тест для CTR (агрегация по 50 бакетам) | p-value ≈ 2.7e-07 — различия подтверждены |

### Почему t-тест не сработал на сырых данных
Исходное распределение CTR имеет тяжёлые хвосты и высокую дисперсию — нарушается предположение о нормальности. Сглаживание и непараметрические тесты решают эту проблему.

## Выводы

1. **Эффект неоднороден:** новый алгоритм помог небольшой части пользователей (заметный рост CTR), но ухудшил показатели у большинства.
2. **Средние почти не изменились,** но выросла доля пользователей с низким CTR — алгоритм стал работать менее стабильно.
3. **Гипотеза о причине:** алгоритм может быть слишком узконаправленным (хорош для одних сегментов, плох для других) или ошибается в предсказаниях на основе прошлого поведения.

---

## Рекомендация

Не раскатывать алгоритм на всю аудиторию. Необходим сегментированный анализ (по возрасту, гео, паттернам поведения) для выявления групп, на которых алгоритм работает хорошо, и групп, где он даёт сбои. После доработки — повторный A/B-тест.

---

## Ограничения (учебного проекта)

- Данные симулированные — выводы не применимы к реальному продукту.
- Не проводился AA-тест для проверки системы сплитования.
- Не оценивалась длительность эксперимента (7 дней — достаточен ли срок для замеров?).
- Не анализировались другие метрики (конверсия в покупку, retention, время в ленте).
